# Projeto de Vida — Ronald | Engenheiro de Software

Projeto web desenvolvido em **HTML5**, **CSS3** e **JavaScript** puro, pronto para ser aberto e editado no **Visual Studio Code**.

## Estrutura de Pastas
- `index.html` — Estrutura principal da página.
- `css/style.css` — Estilização responsiva com tema escuro e tema claro.
- `js/script.js` — Interatividade (barra de progresso das metas, filtros por prazo, alternância de tema e menu responsivo).

## Como abrir no VS Code
1. Extraia o arquivo `.zip` em uma pasta no seu computador.
2. Abra o **VS Code**, clique em **Arquivo > Abrir Pasta** e selecione a pasta extraída.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code para visualizar em tempo real.
